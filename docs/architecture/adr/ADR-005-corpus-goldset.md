# ADR-005 真实测试语料设备与人工金标

- 状态：PROPOSED；决议 OPEN；日期2026-10-24；批准人待用户确认。
- 关联：D07/D10，P0-00/03/04/09；v1.1 §§9.2–9.4、11.2。

## 问题与候选

当前无本地 PDF/标注/Win11 设备。可先采用资源登记表中的两篇 ACL 官方论文作英文冒烟候选，再补目标领域中英、复杂表格、扫描/混合、旋转/CropBox；也可由用户提供许可明确的实际论文。两个英文候选不能代表千篇目标库。

## 证据和裁定方法

候选来源/许可已查网页，PDF未下载，SHA/实际页数/金标未知。获取后冻结 corpus Manifest、各版本哈希和合法用途，独立记录科学问题/表格条件/页区域与双轮人工复核。按30–50篇及120–200题→100–200篇→真实约1000篇逐级扩展；这些是原方案建议规模，无数据不得声称达成。缺规模报告不足，不拿复制或合成论文凑数。

## 提议与回退

用户指定领域、资料来源/使用范围、人工标注及复核负责人、8/16GB干净Win11操作人；在正式测量前批准采样/质量合格线和误差定义。缺金标只做工程测试，科研质量 BLOCKED。语料受限时仅记录哈希与许可，不上传或公开；替换样本建立新 dataset 版本，不覆盖失败记录。无设备不以 macOS 或 CI 冒充。
