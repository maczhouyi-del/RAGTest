# ADR-006 性能质量门槛与阶段范围

- 状态：PROPOSED；决议 OPEN；日期2026-10-24；批准人待用户确认。
- 关联：D05/D10，P0-00/06/09/10、P2；v1.1 §§9.2–9.5、10.1、10.4。

## 问题与候选

1000篇/4–8万Chunk/向量容量是估算；16GB CPU 混合检索P95争取≤1s为建议初始目标，排除query Embedding/Rerank/LLM。P0启动包用分项FTS/exact验证，P2才完成混合检索。源文§10.4包含最小问答和自动化CI；本轮用户明确只做本地审查，尚未批准P0完整生成问答或远端CI。

## 证据和裁定方法

当前无任何性能/科研质量测量。须在看正式结果前登记语料、硬件、查询与过滤、冷/热状态、并发、预热、轮数、计时边界、percentile计算方法、失败/超时计数；同时冻结解析/定位/表格绑定指标和合格线，避免测后调门槛。允许独立试验集探索阈值，正式验收集须冻结且标明划分。

## 提议与回退

建议P0仅检索/来源技术闭环、不实现P3 Claim问答，以用户确认范围为准；本地脚本暂承担可复现构建验证，保留长期自动化需求。P0报告组件实测，不提前宣布混合目标PASS；ANN需exact不达已批准预算再提案。门槛缺失保持OPEN，不能追认成绩。失败保留全部记录并修复，不降低G01—G14；核心未过不进P1。所有范围与指标变更需用户批准并注明替代章节。
