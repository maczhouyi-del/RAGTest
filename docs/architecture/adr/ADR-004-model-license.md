# ADR-004 模型运行时许可与离线资源

- 状态：PROPOSED；决议 OPEN；日期2026-10-24；批准人待用户确认。
- 关联：D03/D08，P0-00/03/05/09；v1.1 §§4.4、8.1、8.5、11.2。

## 问题与候选

本地轻量多语言 ONNX 是评测方向，不是具体模型决议。候选 A：许可明确且 Windows CPU 可打包的轻量本地模型；B：多个本地候选进行中英检索/内存/速度比较；C：模型不可用时明确阻塞向量功能，只保留可用关键词功能。当前不提议付费云替代。

## 证据和裁定方法

尚无模型卡/revision、权重、tokenizer 哈希、质量、内存或许可审查。任何库代码许可证不能代替权重/OCR模型再分发许可。先登记官方来源、精确版本和SHA、许可文本、NOTICE、用途/再分发限制、安装和按需下载大小；再在同一金标和 Win8/16GB CPU 上评测检索与推理。EmbeddingSpace 包含 tokenizer/预处理/维度/距离/归一化/权重全指纹。

## 提议与回退

保持模型选择 OPEN；实际安装/下载前列明确对象和附带变更，按用户授权执行。禁止库初始化隐式自动拉取 Docling/OCR/Embedding 权重。模型缺失明确展示能力，不伪造 Embedding。参数变化建新空间，旧 ACTIVE 和持久向量保留；失败空间不可发布，不触碰原件。当前无模型下载/API费用或用户内容外发授权。
