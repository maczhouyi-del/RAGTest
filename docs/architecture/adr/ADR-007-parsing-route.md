# ADR-007 PDF 质量路由与可选增强解析

- 状态：PROPOSED；决议 OPEN；日期2026-10-24；批准人待用户确认。
- 关联：D02/D08，P0-03/04/09；v1.1 §§2.4、4.1–4.2、8.6、9.2。

## 问题与候选

保留 PDFium快路径→质量诊断→Docling/OCR条件升级方向。候选A：先单页提取，失败/复杂页由可测信号升级；B：部分复杂文献整篇增强但保留原运行和页状态；C：资源/许可不足只标partial/unparsed，不伪装全文成功。不能把PDFium文字非空当作表格/阅读顺序正确。

## 证据和裁定方法

当前无解析器/权重或真实PDF试验，阈值NOT MEASURED。冻结文本覆盖/乱码/顺序/表格/定位信号，独立试验集探索路由；正式金标前预注册指标与合格线。逐页记录parser版本、配置/权重指纹、升级原因、错误/耗时/峰值内存和OCR授权；比较升级前后科学表格条件绑定与页定位。

## 提议与回退

不提前锁库版本/阈值/打包体积；增强只有在具体资源获准且证明改进后启用。离线缺权重拒绝隐式联网。保留ParseRun历史，不覆盖旧映射；失败退回可靠页级或部分状态，不补造Element/bbox。普通侧车不自动构成解析安全沙箱；资源限额与Windows权限/联网限制须有反例实测。
