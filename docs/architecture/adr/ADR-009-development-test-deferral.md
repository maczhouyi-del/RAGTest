# ADR-009 非阻断补测延期与继续开发

日期：2026-10-24（Asia/Shanghai）。依据用户原话：“不影响整体开发的测试可以暂时搁置，标记一下后继续开发下面的功能”。状态：按用户指令执行的有限开发顺序调整；不是P0验收通过或发布批准。

调整PLANS阶段顺序/AGENTS阶段循环第7项的本轮适用边界：P0正式验收仍BLOCKED，允许继续不依赖缺失实机/科研评测的P1本地文献功能。P1开发状态不等同P0/P1验收PASS。不能把未测事项改为通过、删除原门槛或借此锁定向量/解析模型。

Windows干净安装、8GB、Intel/低版本/干净Mac、千篇容量、人工科研金标、最终分发许可/签名评测可以延期，不阻断本轮项目/元数据/阅读实现。具体触发点见deferred-tests.md。这些事项仍约束对应平台兼容、科研质量或发布声明。

不可延期作为本轮开发前置的检查：受影响数据迁移/备份和hash正确性、项目关联/范围过滤、编辑冲突、IPC身份/固定文件授权、来源不虚构、新增功能本机集成/构建。出现实际数据丢失、未授权文件访问或伪来源先修复再继续。P2—P4若依赖新的模型/后端/科研门槛，应先核对对应依赖，不从本指令推断全部豁免。

无核心架构变更；无付费API、模型额外下载、GitHub、旧数据删除/迁移或对外发布授权。可回退开发顺序，保留数据和证据；已经升级的新库不得直接用旧程序打开，需要在新目录恢复升级前备份。
