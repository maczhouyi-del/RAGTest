# MVP-02 待执行原生人工检查

状态：NOT EXECUTED；仅有原生启动回收smoke与浏览器键盘自动化，不把它们当本表通过。建议在新测试工作区，使用两篇已有公开PDF，不使用真实私有论文或付费API。

1. 打开E报告中的新Mac开发app（旧app先正常退出）；用原生对话框导入两篇公开PDF，检查元数据及正文解析，配置现有E5与Qwen目录，不下载资源。
2. textarea英文输入Enter发送，Shift+Enter保留换行；空白Enter不发，快速连按只新增一轮。
3. 切中文输入法，输入拼音后用Enter确认候选；该次不发送。候选结束后再Enter才发送。记录macOS/输入法名称和实际按键。
4. 同一会话三轮，侧栏一条；逐轮引用能回实际PDF。切模型保留历史。Qwen拒答/回答质量单独记录，不改科学标准。
5. 新会话为空且旧会话保留；退出重开，检查完整会话/元数据/索引。模型目录配置保留，API会话密钥应缺失，不自动调用云端。
6. 文献侧栏默认展示，编辑与核对后修改标题/年份/摘要；再解析，人工值不变，失效旧引用明确提示。
7. 原生目录对话框创建备份、恢复到新副本、切换；检查原库保留、文献/元数据来源/会话一致。派生索引缺失时重建应复用已有向量。
