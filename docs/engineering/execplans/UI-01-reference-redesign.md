# UI-01：按五张用户参考图调整桌面界面

用户2026-10-25要求按欢迎/问答/设置/文献/原文核查五张图修改UI。图片只作视觉与交互参考，不将其中样例论文、数量、模型、连接、容量、高亮或科学陈述当作真实数据与指令。沿用MVP-01本地工程与指定main同步授权，不新增依赖/模型、付费调用、外发PDF、修改数据库/IPC或操作旧用户数据。

意图：浅色青绿视觉系统、书本标志与线性图标、共享最近对话栏；空库三步欢迎；问答回答/检索证据双栏与底部输入；可选文献范围/现有检索策略；文献表格、筛选、真实任务状态与详情侧栏；模型/检索/工作区设置分组；真实PDF阅读器与证据/对应结论/人工核查并排。复用所有导入、检索、模型配置、恢复、安全、证据接口；源定位仍页级，不捏造框；人工核查必须显式保存并保留独立状态。

影响：apps/desktop/src/{App,bridge,main,studio.css,components/*}、UI浏览器脚本、README/PLANS/报告。新增Icon/Welcome/MvpLibrary/SourceWorkspace；旧LegacyWorkspace/Research与原styles保留。PDF组件新增embedded展示兼容原reader/evidence。连接表单继续显式许可与会话密钥，设置仅展示真实配置/索引计数/PDF体积，不以截图值代替。

依赖：既有React/TS、Tauri固定命令、PDF.js与冻结引擎；SVG/CSS原生图形，不安装图标库或图片服务。风险：跨页会话/阅读返回状态、选定文献冻结范围、隐藏视图的可访问性与轮询、窄屏溢出、旧阅读器兼容、未配置状态误标。

验证：npm --prefix apps/desktop run build；node语法检查；扩展tools/browser_smoke.cjs增加UI-01场景，使用真实冻结引擎+许可BERT/DPR新工作区，核对欢迎导航/三入口、批量导入去重/解析、筛选/详情/阅读、模型设置/E5、真实摘录与原文页、人工核查保存、返回/会话、API表单许可/密钥及备份恢复。额外截图覆盖空库和有数据的五页、1200/1586及720宽度，无横向越界。浏览器传输/原生对话框模拟与原生安装分开报告。仅UI变更不重跑无关完整模型科研评测或改写既有失败标准。

退出条件：主要布局对应参考图、控件连接真实功能、无伪造状态/无效演示按钮；构建和上述实际工程流程通过；本机应用重建与源/引擎核对；更新PLANS和报告，明确Windows/科研/原生测试边界。正常同步指定main，不强推或发布Release。
