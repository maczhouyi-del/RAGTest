# UI-02：简化文献工作台

2026-11-09 用户授权当前项目 UI 整理：减少标语、重复说明和次要标签，以布局表达用途；同时保持 UX、DX、AX 和原有功能。沿用现有 React/Tauri/引擎架构，仅本地修改验证，不提交、推送或发布。

## 范围与验收

- 空库：一个导入主操作，设置仍由主导航进入；不把可选生成模型或向量索引描述为开始使用的必要步骤。
- 侧栏：品牌、三入口、对话列表；保留新会话、归档、管理与引擎真实状态。
- 问答：删除重复用途说明和标语；保留范围、模型、策略、发送和错误。原文引用优先，冻结范围和诊断可展开检查，真实性/模型支持/人工核对独立呈现。
- 文献：保留筛选、多选、解析/索引状态、任务重试/取消、阅读与元数据；减少重复标签和空队列占位。
- 设置：保留分类、字段标签、授权/费用/凭据/恢复风险；删除重复分类说明、装饰图标和服务宣传。
- 视觉：中性色、单一强调色、减少渐变/阴影/装饰、统一密度；键盘 focus、可访问性名称和响应式布局仍可用。

拟修改：`apps/desktop/src/App.tsx`、`components/{Welcome,ConversationSidebar,MvpAsk,MvpLibrary,MvpSettings,TurnEvidence,SourceWorkspace}.tsx`、`studio.css`；`tools/browser_smoke.cjs` 与 UI 专项浏览器脚本；本计划、PLANS 和本轮报告。实际清单以报告为准。

依赖：已有 React/TS/CSS、浏览器验证依赖、已批准的本地 E5 和公开 BERT/DPR。无新增包、模型、云调用、schema、IPC 或后端变更。仓库已有未提交工程文档保持。

风险：折叠内容的可达性、窄屏横向溢出、对话独立滚动/返回、空库入口变化导致旧定位器失效。用语义按钮/原生 details 表达展开，不用 CSS 隐藏必要状态。

拟执行：`npm --prefix apps/desktop run build -- --emptyOutDir=false`；`node --check`；既有 CHAT_MANAGEMENT 浏览器回归（真实隔离引擎/公开 PDF/E5、本地协议模型 fixture），追加空库/文献/设置/证据/阅读器 1440/1024/720/390 宽度、键盘与折叠检查并截图人工审查。构建不得批量删除旧文件。日志保存在 `docs/engineering/evidence/UI-02-20261109/`。

验收：三入口、导入/解析/索引、问答范围与历史、引用/PDF、归档/恢复/复制、连接错误处理回归通过；主容器无横向越界，控件可操作，状态真实。浏览器模拟传输不等同原生 WebView/Windows 安装；科研质量不在本轮判定。

需求依据：v1.1 §§2/5/6/7，AGENTS §§4/5；既有检索回答、任务恢复和来源契约不变。无架构偏离，不新增 ADR。
