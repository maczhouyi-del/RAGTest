# P2-02 可选本地相关性复核排序与范围筛选

用户连续开发授权；v1.1 §§4.3–4.5、6.1。不下载新模型，以已批准Qwen候选提供可关闭的相关性复核排序，默认检索不变；不把它当已选定的专用Reranker或质量提升结论。

问答任务中新增keyword_review/hybrid_review策略，先做现有候选召回/逻辑论文配额，再将最多6条、每条最多500字符送入已批准本地生成worker，输出编号/0–5相关性判断。要求每个输入恰好出现一次、无新增ID、分数为有界整数；失败显式保留任务及模型指纹，不静默发布。稳定排序仅改输入池顺序，不改quote、来源、原始召回范围；结果持久保存原排序、新排序、模型指纹和理由。摘录模式也可显式选择模型排序，但仍不生成科学结论。整个流程沿用可取消的后台问答任务，避免把180秒推理塞入同步搜索IPC。

修改：models/local_generator.py/generator_worker.py、retrieval/reranking.py、workflows/workbench.py、ipc/server.py、ResearchWorkbench.tsx/SourceSearch.tsx及bridge类型、测试/真实候选试验工具、契约/报告。SourceSearch补元数据标签/年份范围筛选，所选版本列表在召回前传给引擎，项目与可见性仍由SQLite复查。

验证：伪造/重复/遗漏/浮点分数拒绝、稳定并列、原引文不改、取消不发布、来源撤稿仍被屏蔽、模型尝试留痕、真实本地候选一次试验、TS/Rust/冻结包/浏览器受影响流程。真实增益、跨语言召回、千篇性能与科学金标仍BLOCKED。新增提示配置指纹变化后需在设置重新校验，历史观察指纹不覆盖。
