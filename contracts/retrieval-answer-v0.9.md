# 检索与回答增量契约 v0.9 — RAG-03

继承 v0.8；SQLite schema18、既有端点与请求结构不变，不改写历史问答。新增 health.build 为可选字段，旧客户端可忽略；冻结程序提供 built_at/source_sha256/label，源码运行明确标为 source-checkout。构建指纹表示冻结输入，不代表科学质量认证。

## 系统数量与单篇概览

“当前文献库中拥有多少篇文献”等系统数量问法读取当前 SQLite 可见逻辑文献、文件版本与已解析文献数；project_id 存在时限定项目。无检索、无生成、无文献引用；复合问题仍保留科研子句。

单篇贡献/研究问题问法，在已授权且已选择版本范围恰为一个时，补充原文结构候选：贡献/局限句、摘要、结论及同页相邻续段。结构候选上限12，与原检索候选去重后继续应用每篇3/总8配额。参考文献标题之后不进入该结构通道；普通具体问题保留原检索路径。记录 single-document-sections-v1、基线与最终候选，不能把结构启发式当作相关性或科学正确率。

匹配阶段仅对软连字符、换行断词和 U+FFFE 作规范化；实际引用仍为原始 Chunk 文本及原始偏移。不可扩大版本/项目范围；运行和发布继续复核来源、可见性与冻结解析。多篇范围下包含“该文献/这篇/本文/this paper”的概览问题报 DOCUMENT_SELECTION_REQUIRED，要求用户明确选择。

## 官方 DeepSeek 有界生成

仅官方 api.deepseek.com 上的 deepseek-flash / deepseek-v4-pro 显式使用 thinking.type=disabled，以执行当前每请求900输出token的简短结构化回答策略；模型指纹记录策略和提示版本。其他兼容接口不擅自加该参数，不自动换模型或重试。

finish_reason=length 报 MODEL_OUTPUT_TRUNCATED；TLS验证、DNS及连接中断分别报可诊断错误，保留证书验证。旧历史 PROVIDER_UNAVAILABLE 不被追溯改写为某个新错误。输入审计、精确引用、支持性意见和人工审查按 v0.8 继续独立处理。

## UI 与运行产物

每轮显示其保存的文献范围；关键词模式显示中文提问英文资料的局限及切换混合检索入口。设置显示实际侧车构建标识。修改源码不会更新已运行的应用，交付须重新构建、核对侧车 SHA 并启动核验。macOS 独立应用通过 Tauri build 嵌入前端；普通 cargo build 的开发入口不能冒充独立应用交付。
