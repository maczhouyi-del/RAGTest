# 检索与回答增量契约 v0.8 — REMEDIATE-01

继承 v0.7，依据本轮用户整改任务 P1-07、P2-08—11。无数据库迁移，不重写历史结果。新生成适配器必须升级；旧的无输入审计适配器拒绝发布，不能自动回退候选池。

## 模型输入和证据

`context_metadata.contract_version=model-input-v1`，included_chunk_ids / dropped_chunk_ids 是本轮输入 Chunk 的互斥完整划分，元素为唯一且属于输入集合的字符串。excerpt_lengths 与 included 同顺序同数量；记录原文长度、实际长度、is_partial、start=0/end、UTF-8 摘录 SHA256、原始 source 对象的规范 JSON SHA256。当前格式是前缀且≤1200字符，不支持任意偏移冒充前缀。source 绑定文献版本、PDF SHA、当轮 P/V 分组、页和保存题名；冻结 scope 继续检查逻辑论文与 ParseRun。

适配器从最终实际序列化的输入构造审计，不接受模型返回的审计字段；本地预算移除片段后再构造。工作流独立按当轮原文核对，无效返回 MODEL_INPUT_METADATA_INVALID，在支持调用前失败。模型输入收据是可信进程内部契约，不能抵御已被攻破、能伪造正确哈希的适配器；不是外部服务内部推理的远程证明。

生成回答的证据记录只包含实际送出的片段范围；全部检索候选仅在 retrieval trace 保存。每条 Claim 的引用还必须通过实际发送范围匹配、当前来源/版本复核；支持性意见、科学可比性和人工审查独立保存。

## 输出及预算

本地/网络/工作流共享硬限制：每回答最多2条结论，每条非空文本≤2000字符，每条1–5个引用。额外未知字段拒绝；兼容已有 conditions 对象（≤10键，键≤100字符，值≤1000字符），仍未人工验证。输入编号引用在适配器映射为 chunk_id/quote 后工作流再核验。非法 JSON、未知编号、3条以上结论均不可发布。

普通生成最多1次 answer +2次 support，无自动重试；可选本地 review 最多2次，默认关闭。远程响应大小≤1MiB，连接/读取超时30秒，分块循环墙钟检查60秒（阻塞单次读取可能延长至下一次超时）；本地单任务180秒、加载60秒。每次请求最多900输出token（provider明确配置 token_parameter=none 时无法执行远程token硬上限，费用未认证）。未知价格/usage不填0；没有可证明的统一货币费用上限，付费提供方仍依明确授权和服务端额度控制，发行预算验收保留BLOCKED，不虚报费用保障。

## 可选重排

v3在每批≤6个候选内部排序，再按批内名次轮流交织；不同批次的原始分值永不直接比较。各批均无内部偏好时保持完整基线顺序；完整12候选保留，应用层最后仍执行8条/每论文3条配额。保存基线、批次、判断、重排和最终选择。此方案只有确定性/分数平移不变性测试依据，没有科研效果证明，默认仍关闭、scientific_quality=NOT_EVALUATED。启用增益判断必须用同一人工金标比较。

## 筛选

`authorized_doc_version_ids`与 project_id 为硬授权边界，filters 仅在其中取交集。year_from/year_to 为包含端点的区间；tag 精确区分大小写匹配；多条件 AND。缺年份/缺标签不满足对应条件；无对应过滤项不因此排除。检索前应用，空交集 results=[]、scope_status=NO_FILTER_MATCH，既不调用检索器也不要求空范围有模型配置。

原范围仍在检索后检查；筛选快照比较实际元数据及修订，查询期间变化报 SCOPE_FILTER_CHANGED；来源不可用报 SCOPE_NOT_AVAILABLE。无匹配不是冲突。无 filters 时保留现有未配置模型的错误优先序。前端传授权全集和 filters，不再自行缩小授权范围来假装后端过滤。

## 文件版本

AnswerRequest 新增 version_policy，默认 latest_imported：仅在调用者显式版本集合内，每个逻辑 Document 选 created_at 最近的文件版本，同时间按 ID 升序稳定破同分。不是科学出版版本排序。explicit_versions 保留明确指定多个版本；MVP界面提供单版本、最近导入可检索版本及全部可检索版本比较选项。旧调用默认收窄多版本范围，单版本不变；Research逐篇覆盖语义不变。

Document=人工逻辑身份，DocumentVersion=不可变PDF文件版本，ParseRun=同一文件的一次解析。重新解析不产生新的文件版本，不改变导入时间；合并保留版本ID/原件/引用。前端来源显示文件指纹和导入时间；撤回/隐藏/项目授权和冻结后解析变化仍失败关闭。历史来源不改写。
