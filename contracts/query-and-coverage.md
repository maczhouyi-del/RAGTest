# 局部问答 vs 全集研究的查询范围契约（P2–P4 预留）

**来源**：v1.1 §§4.3–4.5、§6.1、§6.3、§6.5。P0 只实现必要的可授权源检索原型；下列功能不是 P0 完成声明。

## 范围快照

`ScopeSnapshot`: `scope_id`, 授权论文版本 ID 集合、项目 ID（可选）、过滤条件、创建时间、关联 Run/Query ID。每轮查询确定当轮范围；权限变化/文献删除后，按最新允许集合过滤并审计。

- **局部问答（P2/P3）：** 范围过滤 → FTS5 + exact KNN → 融合/可选 Reranker → 每文献配额/去重 → Claim 与 EvidenceSpan（P3）→ 来源有效性/可选语义支持审查 → 限定结论/拒答。
- **候选论文发现（P2/P4）：** 文献级召回，报告检索到的候选数、范围和排除规则；只能称为“候选”，不能宣称穷尽。
- **全集比较（P4）：** 冻结论文版本清单 → 每篇处理状态（queued/running/success/failed/unparseable/not_processed）→ 逐篇结构化提取 → 单位/数据集/实验条件规范化 → 人工复核 → 报告覆盖率。

## 不可越界断言

- Top-K 的命中数不代表“所有论文”或“目前无人研究”。
- `not_found_by_retrieval` 不等于 `explicit_not_reported`：未检索到可保留 `evidence_insufficient`。
- `source_valid` 不等于 `semantic_supported`；语义支持不等于人工确认或科学可比。
- 若一篇论文有多个实验条件/表格行，StudyObservation 应逐行表达，不得自动比较不同单位/数据集/切分方案的数据优劣。
- P4 报告至少公布：总授权论文数、可解析数、逐篇成功数、失败/未处理数、待人工复核数、纳入标准；不能把研究覆盖说成系统综述的外部完备性。
